10. KCF 目标跟踪

目录

  • 10.1 头文件与数据结构
  • 10.2 使用流程
  • 10.3 完整示例
  • 10.4 注意事项

Track 模块在 device 内存上跑 KCF 类相关滤波跟踪器，支持单目标和多目标。 输入必须是 NV12 帧（通常由 VDEC 解出）。

10.1 头文件与数据结构

#include "Edge10/Edge10_track.h"

typedef struct {
    Edge10Rect rect;     /* {x, y, width, height} */
    uint32_t   roi_id;
} Edge10Roi;            /* 初始化时传入的待跟踪目标 */

typedef struct {
    Edge10Rect rect;
    uint32_t   roi_id;
    float      response; /* 响应得分 */
    bool       track_ok; /* 是否仍跟踪上 */
} Edge10Bbox;           /* 每帧输出 */

10.2 使用流程

1. 创建跟踪器

Edge10Track* track = NULL;
Edge10TrackCreate(&track, /*device_id=*/0, /*max_obj=*/4);
/* max_obj：同时跟踪的最大目标数，数组按这个上限开 */

2. 在第一帧给出初始框

Edge10Roi rois[2] = {
    { .rect = { .x =  400, .y = 300, .width = 400, .height = 400 }, .roi_id = 1 },
    { .rect = { .x = 1000, .y = 300, .width = 400, .height = 400 }, .roi_id = 2 },
};
Edge10TrackInit(track, rois, /*num=*/2);

3. 逐帧更新

每帧（NV12，device buffer）调一次 Edge10TrackUpdate：

Edge10Bbox boxes[4];
int32_t num = 0;

Edge10Error ret = Edge10TrackUpdate(
    track,
    frame_buf,          /* Edge10Buffer*：NV12 帧，在 device 上 */
    width, height,      /* 帧实际宽高 */
    width_stride,       /* 行跨度（从 VDEC 拿到的 ws） */
    height_stride,      /* 列跨度（从 VDEC 拿到的 hs） */
    EDGE10_PIXEL_NV12,  /* 像素格式 */
    boxes, &num);       /* 输出：boxes[0..num-1] */

for (int k = 0; k < num; ++k) {
    printf("roi=%u rect=(%d,%d %dx%d) resp=%.3f ok=%d\n",
           boxes[k].roi_id,
           boxes[k].rect.x, boxes[k].rect.y,
           boxes[k].rect.width, boxes[k].rect.height,
           boxes[k].response, boxes[k].track_ok);
}

4. 删除失跟目标

如果某个目标 track_ok == false 持续多帧，可以显式删掉：

Edge10TrackRemove(track, boxes, num);

5. 销毁

Edge10TrackDestroy(track);

10.3 完整示例

  • 单帧 / 短序列：samples/src/single/sample_kcf_track.c
  • 多目标：samples/src/flow/sample_track.c
  • 视频流（VDEC + Track）：samples/src/flow/sample_video_track.c
  • 视频流（VDEC + YOLO 检测 + Track）：samples/src/flow/sample_video_track_detect.c

10.4 注意事项

  • 输入帧必须在 device 内存 上（Edge10Malloc 出来的，或 VDECGetFrameRaw 拿到的 virt）。Host 内存帧要先上传。
  • stride 用 VDEC 返回的 ws/hs，不要用 width/height。
  • 第一次 Update 建议做几次 warmup（示例里 warmup 3 次），计时从 warmup 后开始，否则第一次会包含初始化开销。
  • 跟踪器是有状态的：TrackInit 之后不要随便换分辨率 / 像素格式。
