3. 安装与编译

3.1 环境要求

  • 架构：aarch64（uname -m）。x86_64 上无法运行，只能做文档 / 代码浏览。
  • 内核：期望 5.10.4（其它版本可启动，会打 warning）。
  • EP 模式需要：/opt/edge10pcie-hostdrv/（Host 侧 PCIe 驱动包）。
  • RC 模式需要：/app/lib/hcp、/app/lib/hal、/app/lib/mal（板载 DEngine）。
  • ffmpeg / ffprobe：SDK 内置（third_party/ffmpeg/bin/）。track-video 和 --rc-ep 视频队列依赖它们。也可用系统 ffmpeg，设 FFMPEG=/path/to/ffmpeg 覆盖。

3.2 安装驱动包（EP 模式必做）

sudo dpkg -i edge10pcie-hostdrv_*.deb
sudo systemctl start edge10pcie-hostdrv
sudo systemctl enable edge10pcie-hostdrv

确认 EP 节点起来：

ls -l /dev/host_ipcm0 /dev/host_notifier_userdev
tyepctl status        # 若装了该工具

3.3 安装 SDK

从交付包解压，或直接用仓库根目录的安装脚本：

# 解压（交付包形式）
tar xf edge10-sdk-aarch64.tar.gz -C /opt

# 或在源码目录里安装到 /opt/edge10-sdk（默认路径）
cd edge10-sdk
sudo ./install.sh                 # 装到 /opt/edge10-sdk
# 或自定义路径：
sudo ./install.sh /your/path

安装脚本会复制 include/ lib/ bin/ samples/ docs/ scripts/ bindings/ third_party/（含 third_party/ffmpeg/ 内置静态 ffmpeg）以及 env.sh、Makefile、VERSION、VERSION_MATRIX.md、CHANGELOG.md 等到目标目录，并给 bin/edge10-smi、bin/Edge10-ep-run 加可执行权限。

3.4 加载环境变量

source /opt/edge10-sdk/env.sh

env.sh 会把以下路径追加到 LD_LIBRARY_PATH（幂等，多次 source 不重复）：

  • $EDGE10_SDK_ROOT/lib/aarch64
  • $EDGE10_SDK_ROOT/third_party/dengine/lib
  • /opt/edge10pcie-hostdrv/lib
  • /app/lib/hcp、/app/lib/hal、/app/lib/mal

并把 $EDGE10_SDK_ROOT/bin 加到 PATH。

注意：env.sh 不设置 EDGE10_SDK_CONFIG / DEVPROP_INI。 这两个变量由 Edge10-ep-run 包装器或 edge10 --ep 按需设置。RC 二进制 反而需要“干净”的环境——如果手动导出了 EDGE10_SDK_CONFIG 再跑 *_rc， 会错误地走 EP 初始化而崩溃。

3.5 编译 SDK 本身（源码开发时）

cd edge10-sdk

# 编 EP 版（在 Host 上跑，链接 Host 侧 dengine）
./build_ep.sh       # -> lib/aarch64/libEdge10.so

# 编 RC 版（在板载 NPU 上跑，链接 /app/lib/hcp）
./build_rc.sh       # -> lib/aarch64/libEdge10_rc.so

3.6 编译示例

bash build_samples.sh

产物：

  • samples/bin/ep/<name>_ep、samples/bin/ep/flow_<name>_ep
  • samples/bin/rc/<name>_rc、samples/bin/rc/flow_<name>_rc

build_samples.sh 会自动把所有 samples/src/single/*.c 和samples/src/flow/*.c 分别编出 EP / RC 两个版本。

3.7 验证安装

edge10-smi          # 本地 + EP 统一监控（详细表 + 紧凑单行 + 循环刷新）

能列出设备温度 / 频率 / 显存 / PCIe 链路即说明驱动与 SDK 就位。

3.8 在你自己的工程里链接 SDK

最小链接命令（参考 build_samples.sh）：

# RC 版（在板载上）
cc your_app.c -std=gnu11 -O2 \
    -I$sdk/include -I$sdk/include/Edge10 -Isamples/src \
    -DEDGE10_TARGET_RC \
    -L$sdk/lib/aarch64 -lEdge10_rc -lpthread -ldl -lrt -latomic -lm \
    -Wl,-rpath,$sdk/lib/aarch64 \
    -Wl,-rpath,/app/lib/hcp -Wl,-rpath,/app/lib/hal -Wl,-rpath,/app/lib/mal \
    -o your_app

# EP 版（在 Host 上）
cc your_app.c -std=gnu11 -O2 \
    -I$sdk/include -I$sdk/include/Edge10 \
    -L$sdk/lib/aarch64 -lEdge10 -lpthread -lrt -latomic -lm \
    -Wl,-rpath,$sdk/lib/aarch64 \
    -Wl,-rpath,/opt/edge10pcie-hostdrv/lib \
    -o your_app_ep

EP 版运行时必须用 Edge10-ep-run your_app_ep ... 或 edge10 --ep your_app_ep ...启动，不能直接执行。
