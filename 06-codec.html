6. 硬件编解码（Codec）

目录

  • 6.1 头文件
  • 6.2 payload_type 取值
  • 6.3 VDEC：解码
  • 6.4 VENC：编码
  • 6.5 完整示例

Codec 模块封装两路硬件单元：

  • VDEC：JPEG / H.264 / H.265 码流 → NV12 帧（device 内存）。
  • VENC：NV12 帧 → JPEG / H.264 / H.265 码流。

6.1 头文件

#include "Edge10/Edge10_codec.h"

6.2 payload_type 取值

值 宏（示例里常用） 含义
26 PT_JPEG JPEG 静图
96 PT_H264 H.264 Annex-B
265 PT_H265 H.265 / HEVC Annex-B

6.3 VDEC：解码

配置与创建

Edge10VdecConfig cfg;
memset(&cfg, 0, sizeof(cfg));
cfg.width         = 1920;
cfg.height        = 1080;
cfg.payload_type  = PT_H264;   /* 26 / 96 / 265 */
cfg.ref_frame_num = 4;         /* 视频流建议 2~4，JPEG 不需要 */

Edge10Vdec* dec = NULL;
Edge10VdecCreate(&dec, /*device_id=*/0, &cfg);

工作循环

VDEC 是“送一包、取多帧”的异步状态机：

/* 1. 把一帧码流（或一个 NAL）送进解码器 */
Edge10VdecSendPacket(dec, dev_ptr, packet_size);

/* 2. 非阻塞取帧：把当前已经解好的帧全部取走 */
void*    virt = NULL; uint64_t phy = 0;
int32_t  w=0, h=0, ws=0, hs=0, fmt=0;
while (Edge10VdecGetFrameRawTimeout(dec, &virt, &phy,
                                    &w, &h, &ws, &hs, &fmt,
                                    /*timeout_ms=*/0) == EDGE10_SUCCESS) {
    /* 处理 virt 指向的 NV12 帧，注意用 ws/hs 而不是 w/h */
    Edge10VdecReleaseFrame(dec);   /* 用完必须归还 */
}
/* 返回 EDGE10_ERR_BUF_EMPTY 表示当前没有更多帧 */

阻塞取帧 vs 超时取帧

函数 行为
Edge10VdecGetFrameRaw(dec, &virt,&phy,&w,&h,&ws,&hs,&fmt) 永久阻塞，直到出一帧
Edge10VdecGetFrameRawTimeout(..., timeout_ms) <0 永久阻塞；0 非阻塞；>0 最多等 N ms。无帧返回 EDGE10_ERR_BUF_EMPTY

生产视频流水线必须用 GetFrameRawTimeout(..., 0) 非阻塞取帧，配合SendPacket 循环；最后用 Flush 排空驱动内部缓存。

收尾

/* 码流送完后，发 Flush 让解码器吐出剩余帧 */
Edge10VdecFlush(dec);

/* 继续用 GetFrameRawTimeout 排空，直到连续多次返回 BUF_EMPTY */
while (...) {
    ret = Edge10VdecGetFrameRawTimeout(dec, ..., /*timeout_ms=*/1);
    if (ret == EDGE10_ERR_BUF_EMPTY) { /* 短暂 sleep 后重试，或判定结束 */ }
    Edge10VdecReleaseFrame(dec);
}

Edge10VdecDestroy(dec);

重要：每一帧 GetFrame* 返回后，必须调用 Edge10VdecReleaseFrame 才能取下一帧；不归还会很快耗尽解码器内部帧池。

帧参数说明

GetFrameRaw* 返回的 width_stride / height_stride 是硬件分配的行跨度 （通常按 16/64 字节对齐），真实帧数据大小按 stride 算：

size_t frame_bytes = (size_t)ws * hs * 3 / 2;   /* NV12 */

6.4 VENC：编码

Edge10VencConfig ecfg;
memset(&ecfg, 0, sizeof(ecfg));
ecfg.width        = 1920;
ecfg.height       = 1080;
ecfg.payload_type = PT_JPEG;    /* 26 / 96 / 265 */
ecfg.qp           = 80;        /* 仅 JPEG 有效：0~100，越大越清晰，默认 80 */
/* ecfg.bitrate / frame_rate / gop / rc_mode 留给 H.264/H.265 */

Edge10Venc* enc = NULL;
Edge10VencCreate(&enc, 0, &ecfg);

/* 把 NV12 包装成 Tensor 喂进去 */
Edge10Tensor* frame = NULL;
const int64_t dims[2] = { h * 3 / 2, w };
Edge10TensorCreate(&frame, 0, dims, 2, EDGE10_DT_UINT8);
Edge10VencSendFrame(enc, frame);

/* 取码流包 */
void* pkt = NULL; size_t psz = 0;
Edge10VencGetPacket(enc, &pkt, &psz);
/* fwrite(pkt, 1, psz, of); */
Edge10VencReleasePacket(enc);

Edge10TensorDestroy(frame);
Edge10VencDestroy(enc);

状态：JPEG / H.264 / H.265 编码均可用。

6.6 命令行

# 解一段 H.264
edge10 --rc video_decode_rc -i /tmp/car.h264 --ptype 96 -w 1920 -h 1080 -o /tmp/out.nv12

# JPEG 编解码转存
edge10 --rc flow_codec_rc -i /tmp/in.jpg -o /tmp/out.jpg -w 1920 -h 1080 --qp 85
