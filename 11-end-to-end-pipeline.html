11. 端到端 Pipeline

目录

  • 11.1 链路总览
  • 11.2 例子 1：单张 JPEG → 分类（sample_pipeline.c）
  • 11.3 例子 2：H.264/H.265 视频流 → 逐帧分类（sample_video_pipeline.c）
  • 11.4 性能要点
  • 11.5 命令行

把上面所有模块串起来：JPEG/H.26x → VDEC → VPC → 模型推理 → 结果。 本章用两个最典型的例子讲清楚每一步的对接点。

11.1 链路总览

文件 / 网络码流
   │  H2D 拷贝到 device
   ▼
VDEC（JPEG 或 H.264/H.265 → NV12，带 stride）
   │  virt/phy + (w,h,ws,hs,fmt)
   ▼
VPC resize（→ 模型输入尺寸，如 224x224 NV12）
   │
   ▼
VPC cvtcolor（NV12 → RGB planar，直接写进 ctx input buffer）
   │
   ▼
ExecutorInfer(exec, NULL, out)   // 传 NULL 跳过输入拷贝
   │
   ▼
out Tensor（Host 侧 float）→ 后处理（Top-5 / NMS）

11.2 例子 1：单张 JPEG → 分类（sample_pipeline.c）

完整源码：samples/src/flow/sample_pipeline.c。关键对接：

Edge10Init(NULL);
edge10_hal_set_device(0);

/* 1. VDEC 解 JPEG */
Edge10VdecConfig vcfg = {0};
vcfg.width = jw; vcfg.height = jh; vcfg.payload_type = PT_JPEG;   /* 26 */
Edge10Vdec* dec = NULL;
Edge10VdecCreate(&dec, 0, &vcfg);

/* 2. Executor + 模型 */
Edge10Executor* exec = NULL;
Edge10ExecutorCreate(&exec, 0);
Edge10ExecutorLoadModel(exec, model_path);

/* 3. 把模型输入 buffer 拿出来，让 VPC 直接写进去 */
Edge10Context* ctx = NULL;
Edge10ExecutorGetContext(exec, &ctx);
Edge10Tensor* ctx_in = NULL;
Edge10GetInputTensor(ctx, 0, &ctx_in);
Edge10Buffer* in_buf = NULL;
Edge10TensorGetBuffer(ctx_in, &in_buf);
void* in_virt = NULL; uint64_t in_phy = 0; size_t in_sz = 0;
Edge10GetVirtAddr(in_buf, &in_virt);
Edge10GetPhysAddr(in_buf, &in_phy);

/* 4. 送 JPEG 进 VDEC */
Edge10VdecSendPacket(dec, jpg_dev, jsz);
void* nv_virt = NULL; uint64_t nv_phy = 0;
int32_t nw, nh, nws, nhs, nfmt;
Edge10VdecGetFrameRaw(dec, &nv_virt, &nv_phy, &nw, &nh, &nws, &nhs, &nfmt);

/* 5. VPC：NV12 → 224x224 NV12 → RGB planar（直接写 in_virt/in_phy） */
edge10_hal_pic s_pic = { nv_virt, nv_phy, (uint32_t)(nws*nhs*3/2),
                          nw, nh, nws, nhs, /*NV12=*/1 };
edge10_hal_pic m_pic = { /* 224x224 中间 buffer */ };
edge10_hal_pic r_pic = { in_virt, in_phy, (uint32_t)in_sz,
                          TW, TH, TW, TH, /*RGB_PLANAR=*/70 };
edge10_hal_vpc_resize(0, &s_pic, &m_pic, TW, TH);
edge10_hal_vpc_cvtcolor(0, &m_pic, &r_pic);

/* 6. 推理：in=NULL，因为输入已经在 ctx_in 里了 */
Edge10Tensor* out = NULL;
const int64_t out_d[2] = {1, 1000};
Edge10TensorCreate(&out, -1, out_d, 2, EDGE10_DT_FLOAT);
Edge10ExecutorInfer(exec, NULL, out);

/* 7. 读 out */
Edge10Buffer* b = NULL; void* v = NULL;
Edge10TensorGetBuffer(out, &b);
Edge10GetVirtAddr(b, &v);
/* 打印 Top-5 ... */

/* 8. 释放 */
Edge10VdecReleaseFrame(dec);
Edge10TensorDestroy(out);
Edge10VdecDestroy(dec);
Edge10ExecutorDestroy(exec);
Edge10Finalize();

11.3 例子 2：H.264/H.265 视频流 → 逐帧分类（sample_video_pipeline.c）

完整源码：samples/src/flow/sample_video_pipeline.c。与上面的区别只是把“单张 JPEG”换成“循环送 NAL + 非阻塞取帧”：

/* 逐 NAL 送进 VDEC */
for (int i = 0; i < n_nals; ++i) {
    if (!is_vcl(stream, starts[i], lens[i])) continue;   /* 跳过 SPS/PPS */
    Edge10VdecSendPacket(dec, stream_dev + starts[i], lens[i]);

    /* 把当前已解出的帧全部取走（非阻塞） */
    void* nv=NULL; uint64_t np=0;
    int32_t dw,dh,dws,dhs,dfmt;
    while (Edge10VdecGetFrameRawTimeout(dec, &nv, &np, &dw, &dh,
                                        &dws, &dhs, &dfmt, 0) == EDGE10_SUCCESS) {
        /* VPC resize+cvtcolor -> ctx input */
        /* Edge10ExecutorInfer(exec, NULL, out_t); */
        Edge10VdecReleaseFrame(dec);
    }
}

/* 码流结束：flush，排空驱动里残留的帧 */
Edge10VdecFlush(dec);
int empty_retry = 0;
while (empty_retry < 100) {
    if (Edge10VdecGetFrameRawTimeout(dec, &nv, &np, &dw, &dh,
                                     &dws, &dhs, &dfmt, 1) != EDGE10_SUCCESS) {
        empty_retry++;
        nanosleep(& (struct timespec){0, 1000*1000}, NULL);
        continue;
    }
    empty_retry = 0;
    /* 处理 nv ... */
    Edge10VdecReleaseFrame(dec);
}

11.4 性能要点

  1. 零拷贝：VPC 输出直接写 Edge10ExecutorGetContext 拿到的 input buffer，然后 Edge10ExecutorInfer(exec, NULL, out) 跳过 stage 输入拷贝。
  2. H2D 大块传：整段码流一次性上传到 device，再按 NAL 切片送 VDEC，不要每帧都 H2D。
  3. 非阻塞取帧：GetFrameRawTimeout(..., 0) 一次取干，不要用阻塞版在循环里，否则会多一次上下文切换。
  4. 每帧 ReleaseFrame：忘了还帧，VDEC 帧池很快耗尽。
