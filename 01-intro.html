1. Edge10 SDK 简介

目录

  • 1.1 支持场景
  • 1.2 能力总览
  • 1.3 不覆盖
  • 1.4 代码约定

Edge10 SDK 是面向 Edge10 / XJ-A300 算力卡的 C99 封装层，在 DEngine（TyHCP / TyDsmi / TySyslink / TyTVM）之上提供一套统一、跨模式的C API。业务代码只需要 #include "Edge10/Edge10_all.h"，无需直接接触DEngine 的 DCL / DSMI 接口。

1.1 支持场景

SDK 覆盖三种部署模式，同一份业务源码可以同时编出三种二进制：

模式 说明 初始化 链接库
RC 程序直接跑在 NPU 芯片上，调用板载原生 NPU Edge10Init(NULL) libEdge10_rc.so
EP（PCIe Host） 程序跑在 Host，通过 PCIe 远程调 EP 侧 NPU Edge10Init(".../sdk_host_pcie.cfg") libEdge10.so
Parallel（RC+EP） RC 进程与 EP 进程同时跑，两路并行吞吐 分别按上两种初始化 两个 .so

性能参考（实测）： - 纯推理循环（resnet50 单次）：RC ~10ms / EP ~12ms - 视频转码（30s 1280x720 H.265→H.264）：RC 6.3s / EP 13.8s - 单张图片推理（classify 1920x1080）：RC ~500ms / EP ~750ms EP 仅在"单次大数据量"任务上有优势；小任务高频调用 RC 更快。

1.2 能力总览

模块 头文件 能力
运行时 Edge10.h 初始化 / 反初始化、版本、日志、错误串
设备 Edge10_device.h 本地 / 远程设备枚举、信息、PCIe 链路、复位
内存 Edge10_memory.h 设备 / Host 显存分配、自动方向拷贝、物理地址
模型 Edge10_model.h 加载模型、Context、同步 / 异步推理、Tensor
执行器 Edge10_executor.h 高层封装：LoadModel + Infer（推荐入口）
VPC Edge10_vpc.h 硬件 resize / crop / 色彩空间转换
Codec Edge10_codec.h VDEC（JPEG/H.264/H.265→NV12）、VENC（NV12→JPEG/H.264/H.265）
Track Edge10_track.h KCF 单 / 多目标跟踪

1.3 不覆盖

  • 多卡级联、Die 间 RPC、Socket 远程接入（保留 workaround，见 13_故障排查）。
  • H.264/H.265 编解码均已支持（实测 30s 视频转码正常）。

1.4 代码约定

  • 所有 API 返回 Edge10Error，EDGE10_SUCCESS == 0 表示成功；用Edge10GetErrorString() 把错误码转成可读字符串。
  • 所有“创建”接口输出二级指针（如 Edge10Executor**），失败后不要使用该指针。
  • 所有资源都必须配对释放：Create*↔Destroy*、Malloc*↔Free*、TensorCreate↔TensorDestroy。
  • 头文件全部 extern "C"，C / C++ 均可直接包含。
