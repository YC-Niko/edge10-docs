内存（Edge10_memory.h）

目录

  • 设备内存分配
  • Host 内存分配
  • 数据拷贝
  • Cache 一致性
  • 查询 Buffer 属性

设备内存分配

Edge10Error Edge10Malloc(Edge10Buffer** buf, int32_t device_id, size_t size);
Edge10Error Edge10Free (Edge10Buffer* buf);

在指定 device_id 的 NPU 显存上分配 size 字节。device_id 必须是有效设备（通常 0）。用 Edge10Free 释放。

Host 内存分配

Edge10Error Edge10MallocHost(Edge10Buffer** buf, size_t size);
Edge10Error Edge10FreeHost (Edge10Buffer* buf);

在 Host 上分配锁页 / 对齐内存，适合做与设备频繁交换的输入输出。

数据拷贝

Edge10Error Edge10Memcpy(Edge10Buffer* dst, Edge10Buffer* src, size_t size);

自动判断方向（host↔rc / host↔ep / rc↔ep）。 如果你的 src / dst 是裸指针而不是 Edge10Buffer*，用 HAL 层的edge10_hal_memcpy(dst, dstMax, src, count, kind)，kind 取值：

EDGE10_HAL_MEMCPY_H2H = 0
EDGE10_HAL_MEMCPY_H2D = 1
EDGE10_HAL_MEMCPY_D2H = 2
EDGE10_HAL_MEMCPY_D2D = 3

Cache 一致性

Edge10Error Edge10MemFlush     (Edge10Buffer* buf);
Edge10Error Edge10MemInvalidate(Edge10Buffer* buf);

在 Host 写完、设备读之前 Flush；设备写完、Host 读之前 Invalidate。 多数情况下 SDK 内部已处理，裸用 HAL 指针时才需要手动调。

查询 Buffer 属性

Edge10Error Edge10GetPhysAddr (Edge10Buffer* buf, uint64_t* phys);
Edge10Error Edge10GetVirtAddr (Edge10Buffer* buf, void**     virt);
Edge10Error Edge10GetBufferSize(Edge10Buffer* buf, size_t*   size);
Edge10Error Edge10GetBufferDevice(Edge10Buffer* buf, int32_t* device_id);
  • GetPhysAddr：得到设备物理地址，用于 PCIe DataCopy 或 VPC 直接喂edge10_hal_pic.phy。
  • GetVirtAddr：得到 Host 侧可访问的虚拟地址；Host 输入 tensor 在这里memcpy 填数据。
